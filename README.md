Skillup - Digital Product Design

A premium, responsive education platform for a fictional Digital Product Design course.

Skillup is an 8-week intensive designed around practical learning, real projects, live feedback and portfolio development.

Live website: 
https://morexsmile.github.io/Skill-Up/index.html

About the project
Skillup is a multi-page educational website created as a frontend development and UI design project.

The goal was to create a polished, editorial-style experience for a premium digital design course, with a strong focus on:
clear visual hierarchy
responsive design
reusable navigation patterns
accessible and semantic HTML
simple vanilla JavaScript interactions
consistent visual language across multiple pages

The website presents an 8-week Digital Product Design course with live sessions, practical projects, portfolio case studies and weekly critiques.


Features
- Responsive desktop and mobile layouts
- Mobile navigation menu
- Multi-page navigation
- Interactive FAQ accordion
- Course registration form
- Experience selection buttons
- Responsive mentor and curriculum sections
- Custom favicon
- Consistent header and footer across pages
- Hover and transition effects
- Semantic HTML structure
- Vanilla JavaScript without frameworks
- Tech stack
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- GitHub Pages


The project uses vanilla HTML, CSS and JavaScript to keep the code lightweight and easy to understand. The repository is structured around separate HTML, CSS and JavaScript files.


Color palette

Typography

The design uses generous whitespace, rounded elements, muted backgrounds and green accent colors to create a clean premium education aesthetic.
Responsive design
The layout was designed to work across desktop, tablet and mobile screen sizes.
